- preempt_rt: the PREEMPT_RT patch set of the 6.18 series, 6.18.57-rt9, regenerated against linux-xlnx 6.18.40 (xlnx_rebase_v6.18_LTS); the header of the patch says what it contains and what was changed. PREEMPT_RT itself is in mainline since 6.12 (CONFIG_PREEMPT_RT in the defconfig, without EXPERT); on the arm64 KV260 the set adds the printk fix that starts the console kthreads later, /sys/kernel/realtime and the -rt9 version suffix.
- cma_default_heap: mainline's "dma: contiguous: Check return value of dma_contiguous_reserve_area()" (c33efdfcfa6f, v7.0), which linux-xlnx 6.18.40 lacks although it has the commit that it fixes ("dma: contiguous: Reserve default CMA heap"). When the default CMA area does not fit (256 MB, CMA_SIZE_MBYTES of xilinx_defconfig, in a 256 MB Xen domain of runPHI), the kernel registered a NULL area as a dma-buf heap and crashed at boot in dma_heap_add().
