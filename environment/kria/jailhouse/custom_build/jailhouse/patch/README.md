
- linux_vanilla: This patches are usefull when loading jailhouse in a kernel versione grater then 5.7 that is not been patched to run on jailhouse. However the kernel need the kprobe module enabled in the kernel config.
- omnv: the Omnivisor fork (628a02d8) on the KV260, applied with -d omnv (environment_cfgs/kria-jailhouse.sh, JAILHOUSE_PATCH_ARGS):
  - 0001-pyjailhouse-the-Omnivisor-s-cell-header-and-cell_load.patch: pyjailhouse (used by "jailhouse cell linux" and the config tools) did not follow the Omnivisor's structures: its cell parser missed num_rcpu_devices and num_fpga_devices and read the memory regions 8 bytes off, its image loader looked for CONFIG_OMNV_FPGA in a config.h that does not exist (without importing os) to choose the cell_load layout, and used the ioctl number of the structure without the remote-CPU fields.
  - 0002-configs-kv260-linux-demo-the-Omnivisor-root-cell-s-ivshmem-links.patch: zynqmp-kv260-linux-demo.cell had another board's ivshmem configuration (memory, devices, INTx): now the links of the KV260 root cells.
  - 0003-arm64-zynqmp-return-all-the-results-of-forwarded-SIP-calls.patch: the root cell's firmware calls returned only the low 32 bits of x0, so every value Linux read from the firmware under Jailhouse was lost; now x0-x3.
